# Tool notes

One file per program. What it is good for, how to drive it, and where it will
mislead you.

Split by program rather than kept in one file because the unit of retrieval is
"which program am I using right now", and because contributions arrive one
program at a time.

| | |
|---|---|
| [freecad.md](freecad.md) | geometry, FEM pre-processing, result handling |
| [calculix.md](calculix.md) | `ccx` solver and the keyword deck |
| [cgx.md](cgx.md) | CalculiX's own pre- and post-processor |
| [gmsh.md](gmsh.md) | meshing |

Findings that represent a genuine weakness in the open-source stack also go into
[../GAPS.md](../GAPS.md), which is the project's register of what needs filling.
These files are for using the tools as they are.
