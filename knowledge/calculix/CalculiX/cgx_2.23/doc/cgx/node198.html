subm 

   'subm' <submenuName> <name> <command>
This keyword is used to add a cgx command line to the menu like ”menu”. The difference is that this command creates or extends a submenu which allows the user to bundle related commands. This subm commands are usually stored in a “.cgx” file in the home directory to link them to the menu during startup.
