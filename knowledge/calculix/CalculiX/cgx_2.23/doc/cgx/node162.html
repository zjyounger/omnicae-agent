qint 

   'qint' RETURN 'w'|'l'|'q'
This keyword is used to extend two lines to their intersecting location. The end-points of the two lines are moved to the intersecting location but they are not merged. Use the ”merg” command to merge duplicate points. Since only straight lines and splines are supported it is necessary to convert other line types into splines before this command can be used (see ”qseq”).

Select lines with the ”l” key. Press ”q” to quit the command.
