# 八配重曲轴：按质量矩设计的第一版

此前的曲轴配重只是几何概念。这一版按现有连杆组件的 CAD 质量与重心，
重新确定每个曲拐两侧配重的轮廓，并完成局部旋转质量矩与装配间隙检查。

![八块配重区域](counterweights_highlight.png)

## 文件

- `crankshaft.FCStd` / `crankshaft.step`：新版独立曲轴，保留原生特征树。
- `short_block.FCStd` / `short_block.step`：新版完整装配。
- `short_block_cutaway.FCStd`：新版可转动剖视装配。
- `inspection_view.FCStd`：金色标示配重区域的检查视图；颜色分区不表示独立零件。
- `counterweight_profile.png` / `.svg`：单片轮廓尺寸与旧轮廓比较。
- `design_parameters.json`、`verification.json`：设计数据与实际测量结果。
- `cutaway_verification.json`：剖视装配与完整装配的曲轴运动一致性。

原先的 FreeCAD 文件和 Blender 点火动画保持为旧版本；它们不会自动切换
成此处的新曲轴。后续曲柄连杆分析应明确选用本目录的几何。

## 材料与目标

曲轴采用 **42CrMo4 +QT**，密度 **7800 kg/m³**，依据
[Ovako 钢厂典型物性](https://steelnavigator.ovako.com/steel-grades/42crmo4/)。
连杆、盖、螺栓及等效钢背轴瓦暂按相同密度，小头衬套按假设的 8800 kg/m³。

配平目标是 **100% 等效旋转质量，0% 往复质量**。这是本轮明确选择的设计点，
没有把它称作所有直四发动机的最优比例，也没有声称消除了二阶往复惯性力。
见 `DEFINITION.md` 中的公式、简化与验收标准。

| 每片下半圆配重区域质量 | 1.3267 kg |

| 曲轴总质量，旧 → 新 | 17.5144 → 20.7118 kg |
| 每曲拐残余质量矩绝对值，旧 → 新 | 28.4293 → 0.006785 kg·mm |
| 新残差 / 连杆等效旋转质量矩 | 0.0221% |
| 72 个角度中最小曲轴—活塞间隙 | 1.709 mm |
| 72 个角度中最小曲轴—缸体间隙 | 2.000 mm |

数值是当前理想 CAD 和假设密度下的计算结果，不代表实物制造精度。
下半圆是为统计与着色定义的配重区域，包含原本也属于曲柄臂的材料；
1.3267 kg 不是相对于旧曲轴新增的质量。

设计程序先求解半径 73.582008… mm，再取 0.01 mm 精度重新测量残差。
用独立的二维面积一阶矩公式复核了三维 CAD 积分。
整圈按 5° 取样，曲轴与其余 82 个零件无实体重叠；另外验证整根曲轴
落在 R73.58 的旋转包络内，活塞裙最低高度为 75 mm，因此刚性几何下
存在至少 1.42 mm 的连续垂直间隔下界。

独立曲轴 FCStd 重开及 STEP 导入的双向差集均为零。其余 82 个零件
与源装配逐件几何比较一致。

## 后续动力学分析的关键限制

等效大小头质量保持连杆组件的总质量和重心，但其两端集中质量转动惯量
比真实 CAD 值高约 **64.6%**。实际绕摆动轴的重心惯量为
**3651.9 kg·mm²**（0.0036519 kg·m²），已保存在数据文件中。
后续完整多体动力学应使用真实质量、重心和惯量，不能把两个集中质量
当成连杆全部动态特性的精确替代。

本轮完成质量矩与冷态装配空间设计。配重重量优化、曲轴柔性及主轴承
载荷优化、圆角和油孔、热态/弹性间隙、强度疲劳和制造平衡公差尚未完成。
增加圆角或油孔、改变连杆或轴瓦质量后，必须重新计算质量矩。

## 复现

1. 在 FreeCADCmd 中运行 `run_design.py`，输出求解参数。
2. 在 FreeCAD GUI 中运行 `build.FCMacro`，生成原生 CAD 和视图。
3. 在 FreeCADCmd 中运行 `check.py`、`check_cutaway.py`。
4. 用带 NumPy/Matplotlib 的 Python 运行 `plot_profile.py` 生成尺寸图。
5. 在 FreeCAD GUI 中运行 `open.FCMacro` 打开检查视图。

曲轴对象的 `CounterweightRadius` 是计算结果记录，设为只读；修改设计应
调整 `design.py` 中的轮廓/目标并重算。原生草图仍可直接编辑，但单独编辑
某一片后原有配平结论即不再适用。
