# Cylinder block and assembled short block

The next stage adds a [Blender ignition animation](ignition/README.md), using
this assembly and a separate simplified display head.

Original CAD geometry matched to the earlier rotating assembly. No downloaded
block model was used. This is the user's requested second stage of the CAD
demonstration, not an OEM reproduction or manufacturing release.

are inspection views, not modified operating hardware.

## Added structure

The new stationary components are the block, five separate main caps, ten main
bearing shells, ten cap bolts and eight cup-shaped coolant core plugs. The block
includes four bores, a closed water jacket with retained cylinder barrels, ten
deck coolant passages, ten head-bolt pilots, external bulkhead ribs, front/rear
seal carrier openings, and an open oil-pan rail with twenty fastener holes.

The original rotating assembly was reused without changing its source FCStd.
All new geometry is generated by `block.py` using FreeCAD's native PartDesign
operations. The sketches retain editable geometry and feature history; they
are not a fully dimension-constrained production sketch system.

## Geometry and verification

See `BLOCK_DEFINITION.md` for the predeclared dimensions and checks. The bore is
86 mm on 96 mm spacing. The deck is 218 mm above the crank axis, leaving 1 mm
above the piston crown at TDC. The native cylinder and barrel surfaces establish
the nominal 4 mm barrel wall. Thermal fits, structural strength and casting
feasibility are not established by this model.

`check_block.py` reopens the saved assembly, measures cylindrical BRep surfaces,
probes material/void at named locations, checks new stationary components
against one another, then checks all 49 moving components against all 34 new
stationary components at 15-degree crank intervals. Existing moving-to-moving
checks remain in `inspection.json` from the preceding stage. Contact without
volume is permitted; overlap over 1e-5 mm³ fails. Sampling is not a continuous
collision proof.

All 83 STEP solids are paired with their native counterparts for two-way
Boolean subtraction and optimal geometric bounding-box comparisons. The
standalone FCStd and STEP are reopened separately, and the input rotating
assembly's SHA-256 is checked for preservation.

### A defect found and corrected

The initial block passed the dead-centre checks but the rod forging intersected
the cylinder mouth at intermediate angles. At 60 degrees, the cylinder-1
intersection occupied X=-156..-132, Y=-42.524..-41.292 and Z=98..101.258 mm,
with approximately 6.4 mm³ overlap. The initial report is preserved in
`block_inspection_initial.json`; `block_initial_interference.brep` contains the
actual intersection solid, and `block_interference_location.json` records its
position.

Eight local rod-clearance pockets, two per cylinder, remove only the affected
lower-mouth regions. Their top is Z=106 mm, below the lowest oil-ring bottom
(Z=115 mm) and the jacket floor (Z=118 mm). The main 86 mm bore remains intact
above these pockets. Final results are in `block_inspection.json`: all 24 sampled
angles have zero moving-to-fixed overlap; the measured rod-to-block distance
at 60 degrees is 1.616 mm. This is a distance at that angle, not a proven
minimum over continuous rotation. All 83 STEP solids pass the geometric
round-trip checks.

## Rebuild

With this directory as `INLINE_FOUR_ROOT`, run `build_block.FCMacro` in FreeCAD.
It reads `inline_four_rotating_assembly.FCStd`; `model.py` supplies the shared
native feature helpers. Then run:

```bash
freecad freecadcmd check_block.py
freecad render_block.FCMacro
freecad open_block.FCMacro
```

If the AppImage cannot mount through FUSE, use the extracted
`squashfs-root/AppRun` in place of `freecad`. The check can run headlessly;
build/render/open require a GUI display. Use separate `-u`/`-s` configuration
files for disposable verification sessions. Run the following from this
directory to encode the saved motion frames:

```bash
ffmpeg -framerate 12 -i block_motion_frames/frame_%03d.png -c:v libx264 \
  -pix_fmt yuv420p -movflags +faststart block_rotation.mp4
```

The block has no finished oil circuit, thrust bearing, end seals, head gasket,
cylinder head or oil pan. Threads, cast fillets and final manufacturing details
remain outside this stage. The cooling cavity is geometry, not a cooling-system
performance result.
